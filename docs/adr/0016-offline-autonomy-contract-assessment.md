# 0016. Optional offline autonomy contract assessment

## Context

A consumer evaluating a method replacement needs a reviewable join between its authority
classification, exact capability scope, immutable method/control identities and current reported
proof. A generic plugin cannot establish the deployment's human owner, live runtime enforcement
or authorization from an offline document.

## Decision

The agentic-engineering plugin ships an opt-in offline assessor. Default invocation reads no input
and does not invoke Go. Explicit assessment accepts one bounded, strictly decoded contract and
compares its consumer declarations with proof, per-report runtime coverage and scoped recovery
reports.

Protected domains are mandatory and replacement is limited to an explicitly classified default.
Every recommendation is confined to one capability, repository, environment and set of operations.
Preregistered plan, bundle and assessment digest joins, every evidence stage, protected outcome
floors and independent positive/intercepted-negative path reports remain required. Changed
provenance, missing facts and unsupported recovery yield holds. Bound failure or expiry cannot be
converted into positive support.

The output is always assessment-only and explicitly reports that execution was not admitted,
mutation was not performed and the supplied evidence was not authenticated. The command never
opens artifact references, changes authority, modifies runtime settings or executes recovery.

## Consequences

Consumers can reproduce a bounded assessment using the packaged command and inspect a synthetic
example before integrating it into their review process. They remain responsible for authenticating
the actual contract owner, immutable bytes, measurement verdicts, independent reviews, runtime
interception and existing recovery authorization. Native admission and real provider integration
require separate proof and remain outside this adapter. An exit-zero assessment is not an
execution permission; consumers must inspect its status and preserve the governing authority.
